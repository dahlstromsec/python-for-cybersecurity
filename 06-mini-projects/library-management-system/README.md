# Library Management System

## Overview

A menu-driven library management system developed in Python. The application manages books, registered users and book loans using text files for data persistence.

## Features

- List books alphabetically by title
- Add and remove books
- Register and remove users
- Borrow and return books
- Search for books by title or author
- Display library statistics
- Export statistics to a report
- Validate user input and enforce borrowing rules

## Technical Concepts

- Functions and modular program structure
- Lists and dictionaries
- File handling and data persistence
- Input validation and exception handling
- Searching, sorting and statistical calculations
- Basic application logic and data consistency

## Requirements

- Python 3
- No external Python packages required

## How to Run

Navigate to the project directory and run:

```bash
python3 library_management.py
```

The application creates the required data files if they do not already exist.

## Data Files

- `books.txt` — book records
- `users.txt` — registered users
- `loans.txt` — active loan records
- `report.txt` — exported library statistics

## Purpose

This project demonstrates practical Python programming skills, particularly file handling, data structures, functions and input validation.
